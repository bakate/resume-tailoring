# Generate before optional resume review

The Candidate supplies a Source Document and Job Posting and requests generation once, after Processing Consent. Source Intake, Job Match, and Tailored Resume Preparation remain underlying phases, but Match Analysis is no longer a mandatory stop before resume preparation. The primary result is a Tailored Resume preview with optional section editing and secondary access to analysis and provenance.

This replaces the explicit post-analysis generation checkpoint in BAK-37. It accepts performing resume preparation before the Candidate reads the Match Analysis in exchange for a shorter path to a usable document. Generation Eligibility and provenance requirements remain applicable; only an ambiguity that prevents a faithful, usable result warrants a preceding targeted question.
